# 《未竟之愿》 / Unfulfilled Wish

> 2D 像素**类魂动作游戏** demo · Unity 6 (URP) / C# · **一人独立开发**

一款以 **「防守即进攻」** 为核心的类魂横版动作 demo:玩家消耗的不是自己的血,而是敌人的**韧性**——靠完美格挡 / 识破削韧,破韧后处决。底层是一套**数据驱动、可插拔的攻击架构**,让加招、加连段、加行为都**不改核心代码**。

---

## 系统亮点

| 系统 | 一句话 |
|---|---|
| **战斗** | 弹反 → 削韧 → 破韧 → 处决 的循环;三种防御(白挡 / 红破)、虚血机制 |
| **数据驱动攻击系统** ⭐ | 三层数据(命中 → 招式 → 连段)+ 两个可插拔相位槽(走位 / 打法);配套自研 `SubclassSelector` 编辑器,让策划零代码配招 |
| **敌人 / Boss** | 主角 / 小怪 / Boss **共用一套状态机底座**;多阶段 Boss、登场与击破演出 |
| **存档 / 重生** | 全局态 / 场景态**双层分离**架构;常驻单例 + 场景内对象的重生协调 |
| **打击感 / 反馈** | 顿帧、震屏、受击闪白(MPB)、对象池;`Time.timeScale` 多方仲裁 |
| **工程** | 通用状态机、ScriptableObject 数据层、自研编辑器工具、Bootstrap 常驻单例 |

## 技术栈
Unity 6 (URP) · C# · New Input System · Cinemachine 3
