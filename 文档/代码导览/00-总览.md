## 一、这是什么游戏

Unity 6 (URP) 2D 像素**魂类动作** demo「未竟之愿」。核心玩法:

- **防反驱动近战**:格挡 / 完美格挡(回血回耐)/ 识破(打断敌人危招);
- **削韧 → 破韧 → 处决**循环:打满敌人韧性条 → 破韧硬直 → 靠近按处决,小怪秒杀、boss 吃大额伤害;
- **火堆存档 + 死亡回滚 + 永久进度**:坐火堆存,死了回滚到上个存档点,但 boss/精英等"永久死亡"只在存档时落盘;
- 一场**多阶段 boss 决斗**(登场名片 + 二阶段怒气 + 击破演出)、分步**教程**、**背包/装备/商店**经济、**对话**、传送门关卡流转。

整体架构是**数据驱动 + 三套状态机三合一(主角/小怪/boss 共用底座)**。

## 三、分层与依赖(谁建在谁之上)

```
┌────────────────────────────────────────────────────────┐
│ 表现层   UI ───(订阅/查询)─→ 几乎所有系统               │
├────────────────────────────────────────────────────────┤
│ 元系统   Save · Economy · Interactables · Level ·        │
│          BossFight · Tutorial                            │
│            ↑ 读写角色状态、驱动关卡/演出                  │
├────────────────────────────────────────────────────────┤
│ 机制层   Combat(韧性) · Skills · Feedback · Audio       │
│            ↑ 被 Player/Enemy 的状态调用                  │
├────────────────────────────────────────────────────────┤
│ 角色层   Player ←打→ Enemy(Mobs / Boss)                │
│            ↑ 都继承 Entity、都用一套 StateMachine        │
├────────────────────────────────────────────────────────┤
│ 底座层   Core(生命周期) · StateMachine(状态机+Entity)  │
│          · Data(SO 定义) · Util(常量/工具)            │
└────────────────────────────────────────────────────────┘
```

**几条主依赖线**(箭头=依赖):
- `Core.GameManager` ──→ `Save`(死亡重生调 PrepareRespawn)、`Player`(Revive)、`Enemy`(Respawn);被 `UI`/`Level`/`Interactables` 调来换场景。
- `Player` / `Enemy` ──→ `StateMachine`(状态机)、`Combat`(韧性)、`Feedback`(顿帧/震屏/闪白)、`Audio`(音效)。
- `Player ↔ Enemy`:互相命中走 `Player_AttackState→EnemyBase.TakeDamage` / `EnemyBase.ApplyHitToCollider→PlayerStats.TakeDamage`。
- `Save` ──→ 几乎所有"有状态"的系统(玩家/背包/装备/技能/怪/门/商店/检查点),把它们序列化进 JSON,读档时逐项 apply。
- `Economy` / `Skills` ──→ `Data`(SO 定义内容);`UI` 是它们的展示端。
- `BossFight` / `Tutorial` ──→ `Enemy`(监听怪死)、`Save`(机关状态)、`UI`(演出/提示)、`Audio`。

## 四、贯穿全局的关键设计(读代码前先记住)

1. **三套状态机三合一**:`StateMachine` / `EntityState` / `Entity` 是通用底座,主角/小怪/boss 的状态机都是空壳子类,逻辑全在底座。每个状态走 `Enter / Update / Exit`。
2. **数据驱动攻击编排**:`EnemyBase` 里招式 = 数据(招池 + 连段),`AttackRunner` 统一跑"段前位移 → 出招 → 段后停顿";位移用**可插拔槽**(`StepMover` 段前 / `AttackDriver` 段中,`[SerializeReference]+SubclassSelector` 在 Inspector 下拉选)。小怪和 boss 共用这一套。
3. **Animator 用 Entry 路由,不用 AnyState**:每个状态在自己的 bool 清掉时 → Exit → 回 Entry 按当前 bool 重新路由(见 `动画驱动分类规范.md`)。
4. **常驻单例进 Bootstrap**:GameManager / AudioManager / SaveSystem / EventSystem 等摆在 `Bootstrap.unity`,`Awake` 里 `DontDestroyOnLoad`;别在别处 new。
5. **存档内存连续**:开过的门、杀过的 permadeath 怪、背包,**只在真读档(死亡/继续/手动读档)时从存档重建,普通过场景保留内存**;落盘只发生在存档时(火堆/新游戏/击破 boss autosave),平时杀怪开门捡东西不写盘。
6. **交互最近优先**:多个交互物重叠时,`InteractTrigger` 每帧选离玩家最近的一个显示提示 + 响应 F,其余闭嘴。
7. **战斗核心循环 = 削韧→破韧→处决**:`PoiseMeter` 削到 0 → 进硬直态(可处决窗口)→ `Player_ExecuteState` 结算;boss 致死交给 `BossFinishUI` 击破演出独占时间/镜头。
8. **打击感靠 Feedback 叠加**:`Hitstop`(顿帧)+ `CameraShake`(震屏)+ `DamageFeedback`(闪白/击退,boss 可设霸体免位移),按事件分档。

## 五、运行时流程(把点串成线)

### ① 启动
`Bootstrap.unity`(常驻单例 Awake→DontDestroyOnLoad)→ `Bootstrapper.Start` → 发布版去 MainMenu / 编辑器跳回上次场景 → 进游玩场景 → `SaveSystem.ApplyOnSceneLoaded` 按存档恢复世界态。

### ② 战斗核心(玩家打小怪)
`PlayerInput` 读攻击键 → `Player_AttackState` 命中帧 `OverlapBox` → `EnemyBase.TakeDamage(伤害, 韧性)` → 扣血 + `PoiseMeter.TakePoiseDamage` → 闪白(`DamageFeedback.Flash`)+ 受击音。韧性归 0 → `OnPoiseBroken` → 进 `Enemy_StunnedState`(可处决)→ 玩家按处决键 `Player_GroundedState.TryStartExecute` → `Player_ExecuteState` → `OnExecuted` 秒杀 + 顿帧/强震/处决音。

### ③ 受击(敌人打玩家)
敌人攻击命中帧 → `EnemyBase.ApplyHitToCollider` → 玩家若在格挡/识破态走对应分支(转虚血/免伤打断敌人),否则 `PlayerStats.TakeDamage` → 进 `Player_StunnedState` + `DamageFeedback.ApplyKnockback` 滑退 + 受击音 + HUD 抖/闪。

### ④ 存档 / 死亡回滚
坐火堆 `CheckpointTrigger→CheckpointManager→SaveSystem.Save`(回满 + 落点)。死亡 `PlayerStats.Die→GameManager.RestartScene`:教程=原地复活;正式=`SaveSystem.PrepareRespawn`(全局态回存档)→ 重载存档场景 → apply(门/怪/背包按存档回滚,内存连续保证过场景不丢)。

### ⑤ Boss 战
玩家进 boss 房 → `BossIntroTrigger`:boss 沉睡 → 登场对话 + 名片(`BossNameCard`)+ 推镜/吼叫 + 血条充满 → `Activate` 开打 + 关雾门(`BossFogGate`)。打 → 削韧/识破/处决(boss 霸体不被击退)→ HP 0 → `MinotaurBoss` 死 → `BossBattleManager.OnBossDefeated` → autosave + `BossFinishUI` 击破演出 → `VictoryGate` 出现,按 F 通关。
